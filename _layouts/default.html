Cloudflare Pages serves /assets/* with max-age=14400 (four hours) while HTML revalidates on every request, and it OVERRIDES any Cache-Control set in _headers — that was measured, not assumed. So a deploy that renames a CSS class hands new HTML to browsers still holding the old stylesheet, and the element renders unstyled. It has happened once already: .hero became .portrait and the masthead photo vanished for anyone who had visited earlier that day. site.time is the build timestamp, so the URL changes on every deploy and never goes stale. It re-fetches ~10 KB on deploys where the CSS did not change, which is a trade worth making. {%- endcomment -%} {%- feed_meta %}
